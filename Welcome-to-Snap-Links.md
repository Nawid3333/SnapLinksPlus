# Welcome to SnapLink
Thank you for giving SnapLinks v3 a try.  Here is a quick tutorial to get you started.

## Introduction
Snap Links lets you "lasso" elements on a page and do things with them.  

By default this is handled by holding down the right mouse button and dragging a selection rectangle around things.  It works with links, images, checkboxes, radio buttons, even java script based links and other "clickable" elements.
