# Snap Links Plus: triage of every open issue and pull request

As of 2026-11-25 (release 3.2.1): **68 open issues, 2 open pull requests.**

How this was made: five read-only Claude Code agents on `glm-5.3-flash` (through Ollama) read every issue with its comments and checked it against the current code, CLAUDE.md, History.md and DevNotes.md. A one-shot GLM pass gave an independent first opinion. `deepseek-v4.1-flash` fact-checked every close recommendation (15 agreed, 3 disagreed, 7 unsure), and the disputed code claims were checked by hand. Where they disagreed, the issue stays open below.

## The maintainer's own issues

- [#38](https://github.com/cpriest/SnapLinksPlus/issues/38) Right-clicking can cause a delay (2014): **probably done.** His idea, doing the heavy work only once the drag starts, is how the code works now: mousedown only creates the objects, the page index is built on the first mouse move (ElementIndexer.js:172). Very large pages can still stutter at that first move.
- [#301](https://github.com/cpriest/SnapLinksPlus/issues/301) Add elements to target to UI (2019): **open feature**, not built. Users ask for the same thing in #249.
- [#351](https://github.com/cpriest/SnapLinksPlus/issues/351) "Ask me" contextual menu (2021): **open feature**, not built. Overlaps #46 and #70.
