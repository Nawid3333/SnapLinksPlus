After a selection, scrolling a scrollable part of a page (a sidebar, a chat list, a feed in its own scroll box) logs an error for every scroll event:

```
TypeError: can't access property "style", elContainer is null   (ElementIndexer.js:333)
```

The capturing scroll listener on `documentElement` publishes `ElementPositionsChanged` even when no drag is going on. `ElementIndexer` then rebuilds its whole index and calls `Search()` with the last drag's rect, and `Search()` throws on the lasso container, which was removed when the drag ended. The throw also stops `SvgOverlay.Reposition()`, which subscribes after it. Scrolling the page itself doesn't trigger this, because that scroll event fires on `document`, above the listener.

- `ElementIndexer` forgets the last drag rect on `DragCompleted` and ignores `ElementPositionsChanged` without one, so scrolling after a drag has ended does no work at all. Scrolling during a drag still updates the selection, as before.
- `BeginDrag()` added another `ElementsSelected` listener on every drag and never removed any. `FirstInit()` now adds it once.
