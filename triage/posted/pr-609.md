Fixes #602, and going by the markup posted there, #537 as well.

When the checkbox input is `display: none` inside its label and a `<span>` in that label draws the box (Shopee Seller Center's EDS checkbox, Prowlarr), the obscured check in `ElementIndexer.Search()` hits that span at the center of the label. The check only accepts a hit on the element, inside it, or on a `LABEL` element itself, so the checkbox was dropped as covered. @s793016 traced this exactly in #602.

Now a hit inside one of the element's own labels (`elem.labels`, so both the wrapping label and `<label for>`) doesn't count as covered. A hit on something inside another element's label still does. I left the existing rule that a hit on any `LABEL` element itself counts as not covered: narrowing that would be a separate change, and it could affect the cases fixed in #540.
